# Invite-only customer event playbook

**Situation:** a B2B company hosts a user event for existing customers and a few selected prospects, and wants to control who comes and how many people per organisation.

---

## Assets

| Asset | Variants |
|---|---|
| Invitation email | One per product line or customer segment, plus one for selected prospects |
| LinkedIn company post | Themes and format, with **no** registration link |
| LinkedIn direct messages | Customer heads-up, prospect heads-up, reminder |
| Languages | Local language plus English where needed |

## Decisions that make it work

- **Segment by product.** Each customer email opens with *their* product and lists it first in the programme, so it reads as personal, not as a mass mailing. With AI drafting, several variants cost about the same effort as one generic email.
- **Enforce exclusivity through the mechanics.** Registration is by replying to the email, with no public form. Put the deadline, headcount per organisation and any catering choice in the email, so one reply answers everything.
- **Use LinkedIn for visibility, not sign-ups.** The post creates interest, while the invitation stays personal.

## Handling RSVPs

Responses usually arrive in a separate tracker and have to go back into the main contact file:

1. Match on name, company and email.
2. **Flag fuzzy matches** (spelling variants, a different employer or email) for a human; don't guess.
3. Add respondents who are missing from the contact list.
4. Colour-code yes / no / needs an answer, and update the summary counts.
5. When editing someone else's Excel file, change only the cells you need, and check that the file still opens in Excel before sending it back.
